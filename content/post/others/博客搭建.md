# 1. 安装Hugo
安装教程见官网：https://hugo.opendocs.io/categories/%E5%AE%89%E8%A3%85
# 2. 初始化hugo项目
```shell
hugo new site myblog
cd myblog
git init
```
# 3. 安装PaperMod主题
在这一步骤中将主题配置为博客仓库的子仓库
```shell
git submodule add \
  https://github.com/adityatelange/hugo-PaperMod.git \
  themes/PaperMod
```

# 4. 配置Hugo 和 PaperMod
hugo的配置文件为项目目录下的`hogo.toml`文件，修改内容如下：

# 8 博客上传至github展示
## 8.1 创建github仓库
仓库名必须命名为 `你的用户名.github.io`, 可见性为公开
## 8.2 关联本地项目到远程仓库
a. 创建 `.gitignore`,内容：
```text
/public/
/resources/
.DS_Store
```
b. 提交本地仓库修改
c. 设置远程仓库地址并推送
```
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
git branch -M main
git push -u origin main
```
## 8.3 配置 GitHub Actions 自动部署
在刚才创建的github仓库的设置中进入GitHub Pages。在 Build and deployment -> Source：选择 GitHub Actions
在本地项目根目录执行`mkdir -p .github/workflows`,创建配置文件`.github/workflows/deploy.yml` 写入内容：
{{< details summary="点击查看完整代码" >}}
```ymal
name: Deploy Hugo Blog

on:
  push:
    branches:
      - main
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: latest
          extended: true

      - name: Build
        run: hugo --minify

      - name: Setup Pages
        uses: actions/configure-pages@v5

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}

    runs-on: ubuntu-latest
    needs: build

    steps:
      - name: Deploy
        id: deployment
        uses: actions/deploy-pages@v4
```
{{< /details >}}
推送部署配置：
```
git add .
git commit -m "add github actions deployment"
git push
```
