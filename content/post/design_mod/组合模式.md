# 组合模式的原理和实现

将对象组织成树形结构，以表示「部分-整体」的层次关系，使客户端可以统一处理单个对象和组合对象。

简单来说，就是把单个对象和由多个对象组成的组合对象当作同一种对象处理，让调用者不必关心当前处理的是单个对象还是一组对象。

```go
package main

import "fmt"

// 统一接口
type HumanResource interface {
    CalculateSalary() float64
}

// 员工：叶子节点
type Employee struct {
    salary float64
}

func (e *Employee) CalculateSalary() float64 {
    return e.salary
}

// 部门：组合节点
type Department struct {
    subNodes []HumanResource
}

func (d *Department) Add(hr HumanResource) {
    d.subNodes = append(d.subNodes, hr)
}

func (d *Department) CalculateSalary() float64 {
    var total float64
    for _, hr := range d.subNodes {
        total += hr.CalculateSalary()
    }
    return total
}

func main() {
    department := &Department{}
    department.Add(&Employee{salary: 10000})
    department.Add(&Employee{salary: 20000})

    subDepartment := &Department{}
    subDepartment.Add(&Employee{salary: 15000})

    department.Add(subDepartment)

    fmt.Println(department.CalculateSalary()) // 45000
}
```

员工和部门都实现了 `HumanResource` 接口。部门可以包含员工，也可以包含其他部门，通过统一调用 `CalculateSalary()`，递归计算整个组织的薪酬总额。
