# 门面模式的原理与实现

门面模式也叫外观模式，为子系统提供一组统一的接口，通过高层接口封装和组合子系统的细粒度接口，让子系统更易于使用。

```go
// 子系统1
type CPU struct{}

func (c *CPU) Start() {
    fmt.Println("CPU 启动")
}

// 子系统2
type Memory struct{}

func (m *Memory) Load() {
    fmt.Println("加载内存")
}

// 子系统3
type Disk struct{}

func (d *Disk) Read() {
    fmt.Println("读取磁盘")
}

// 门面
type ComputerFacade struct {
    cpu    *CPU
    memory *Memory
    disk   *Disk
}

func NewComputerFacade() *ComputerFacade {
    return &ComputerFacade{
        cpu:    &CPU{},
        memory: &Memory{},
        disk:   &Disk{},
    }
}

// 统一封装子系统操作
func (c *ComputerFacade) Start() {
    c.cpu.Start()
    c.memory.Load()
    c.disk.Read()
}

func main() {
    computer := NewComputerFacade()
    computer.Start()
}
```

# 门面模式的应用场景

1. **解决易用性问题**：将多个细粒度接口封装为一个高层接口，让调用者通过更少的接口调用完成复杂操作。同时保留原有细粒度接口，满足调用者的灵活使用需求。
2. **减少跨系统调用开销**：对于跨系统调用，可以将多个细粒度接口封装为一个粗粒度接口，减少网络请求次数，降低通信开销。
3. **封装复杂业务流程**：将涉及多个子系统的业务流程封装到统一接口中，减少调用者对多个子系统的直接依赖。对于分布式事务，也可以将业务流程的协调逻辑封装在门面接口背后，但门面模式本身并不能解决分布式事务问题。
