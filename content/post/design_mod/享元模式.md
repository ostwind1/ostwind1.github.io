# 享元模式的原理和实现

所谓享元，就是被共享的单元。享元模式通过共享可复用的对象，减少重复对象的创建，从而节省内存。

实现原理主要是通过工厂模式，在工厂类中缓存已经创建过的享元对象。当需要使用某个享元对象时，先从缓存中查找，如果存在就直接复用，不存在则创建并缓存起来。


下面是一个棋局游戏中使用全局变量保存共享棋子的享元模式代码：
> golang 一般通过全局变量进行对象的缓存即可，无需专门创建工厂类

```go
// 棋子颜色
type Color int

const (
	RED Color = iota
	BLACK
)

// 享元类：保存棋子可以共享的内部状态
type ChessPieceUnit struct {
	ID    int
	Text  string
	Color Color
}

// 预先创建并保存共享棋子
var chessPieceUnits = map[int]*ChessPieceUnit{
	1: {ID: 1, Text: "車", Color: BLACK},
	2: {ID: 2, Text: "馬", Color: BLACK},
	3: {ID: 3, Text: "相", Color: BLACK},
	4: {ID: 4, Text: "仕", Color: BLACK},
	5: {ID: 5, Text: "帥", Color: BLACK},
	6: {ID: 6, Text: "仕", Color: RED},
	7: {ID: 7, Text: "相", Color: RED},
	8: {ID: 8, Text: "馬", Color: RED},
	9: {ID: 9, Text: "車", Color: RED},
}

// 获取共享棋子
func GetChessPieceUnit(id int) *ChessPieceUnit {
	return chessPieceUnits[id]
}

// 棋子：保存外部状态，并引用享元对象
type ChessPiece struct {
	Unit      *ChessPieceUnit
	PositionX int
	PositionY int
}

// 棋盘
type ChessBoard struct {
	ChessPieces map[int]*ChessPiece
}

func NewChessBoard() *ChessBoard {
	board := &ChessBoard{
		ChessPieces: make(map[int]*ChessPiece),
	}
	board.init()
	return board
}

// 初始化棋盘
func (b *ChessBoard) init() {
	b.ChessPieces[1] = &ChessPiece{
		Unit:      GetChessPieceUnit(1),
		PositionX: 0,
		PositionY: 0,
	}

	b.ChessPieces[2] = &ChessPiece{
		Unit:      GetChessPieceUnit(2),
		PositionX: 1,
		PositionY: 0,
	}
}
```

这里，`ChessPieceUnit` 保存棋子的 ID、名称和颜色，这些信息可以被多个棋子共享，属于内部状态；`ChessPiece` 保存棋子在棋盘上的坐标，属于外部状态。

通过全局 map 保存共享的棋子类型，不同棋盘上的棋子都可以引用同一份 `ChessPieceUnit` 对象，从而避免重复创建和保存相同的棋子信息。

# 享元模式和单例、缓存、对象池的区别

## 享元模式 VS 单例

单例模式中一个类只允许创建一个对象，而享元模式可以创建多个享元对象，每种不同的内部状态对应一个享元对象。

享元模式和多例模式比较相似，但是两者的设计意图不同：多例模式关注创建多个对象，享元模式关注通过共享对象来减少内存占用。

## 享元模式 VS 缓存

享元模式中通过工厂类缓存已经创建好的对象，这里的缓存主要是为了保存和复用对象。

而我们常提的缓存，通常是指用来加速数据访问的数据中间层，例如 Redis 缓存数据库查询结果。两者虽然都涉及缓存，但目的和缓存内容不同。

## 享元模式 VS 对象池

对象池和连接池虽然都是通过复用对象来减少创建成本，但与享元模式中的共享有明显区别。

池化技术中的复用是指重复使用：每个对象在同一时刻通常只能被一个调用者获取和使用，使用完毕后归还对象池，供其他调用者使用，目的是减少对象创建和销毁的成本。

而享元模式中的复用是指共享：多个调用者可以在同一时刻引用同一个享元对象，目的是减少重复对象的创建和内存占用。
